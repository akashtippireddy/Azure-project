# Project Abstract

## Azure Reserved Instances and Savings Plan Analysis

This project focuses on analyzing and comparing different Azure pricing options to help organizations reduce their cloud infrastructure costs. The project studies **Azure Reserved Instances** and **Azure Savings Plans** and evaluates how these pricing models can provide cost savings compared with standard pay-as-you-go pricing.

The analysis considers factors such as resource usage, commitment period, pricing, flexibility, and estimated savings. Different usage scenarios are examined to understand which pricing option can be suitable for different workload patterns.

The project aims to provide a simple and practical cost analysis that helps users understand Azure's commitment-based pricing models and make informed decisions about cloud resource costs. The results will be documented using calculations, comparisons, screenshots, and supporting documentation.

### Technologies Used

* Microsoft Azure
* Azure Pricing Calculator
* Azure Cost Management
* Git & GitHub
* Visual Studio Code
* Markdown

### Expected Outcome

The project will produce a comparative analysis of Azure Reserved Instances and Savings Plans, including estimated costs and potential savings. It will also demonstrate how cloud cost optimization techniques can be applied to reduce unnecessary infrastructure expenses.
