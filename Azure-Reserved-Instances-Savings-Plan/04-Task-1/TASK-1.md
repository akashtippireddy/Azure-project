# Task 1: Establish the Cost Baseline

## Goal

Create a reliable view of current Azure compute usage and pay-as-you-go spending.

## Activities

1. Export at least 30 to 90 days of Azure Cost Management data.
2. Group usage by subscription, resource group, region, service, SKU, and environment.
3. Identify recurring workloads and unusual usage spikes.
4. Record current monthly cost and effective hourly run rate.
5. Document assumptions, exclusions, and data quality issues.

## Deliverables

- Clean usage dataset in `src/data/`.
- Baseline cost summary.
- List of candidate workloads for commitment analysis.

## Acceptance Criteria

- Every candidate workload has an owner and subscription.
- Costs can be traced back to source exports.
- Seasonal or temporary usage is clearly marked.
