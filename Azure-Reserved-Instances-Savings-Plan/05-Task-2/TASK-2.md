# Task 2: Analyze Workload Stability

## Goal

Determine which workloads have stable usage suitable for a reservation or Savings Plan.

## Activities

1. Compare hourly and daily usage over the baseline period.
2. Measure minimum sustained demand, average demand, and peak demand.
3. Check region, VM family, operating system, and instance flexibility.
4. Separate production, development, test, and temporary workloads.
5. Identify planned migrations, scaling events, and decommission dates.

## Deliverables

- Stability classification for each candidate.
- Coverage recommendation and confidence level.
- Risk register for possible overcommitment.

## Acceptance Criteria

- Stable base usage is distinguishable from burst demand.
- Each recommendation includes a documented reason.
- Workload owners validate the assumptions.
