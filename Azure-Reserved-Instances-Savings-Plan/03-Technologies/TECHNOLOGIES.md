- Azure Cost Management and Billing
- Azure Reservations
- Azure Savings Plans for Compute
- Azure Resource Graph
- Azure Advisor
- Azure Monitor

## Analysis and Automation

- Python for cost and coverage analysis
- CSV or JSON exports for repeatable inputs
- Azure SDK or REST APIs for automation
- Power BI or Azure Workbooks for reporting
- Git for version control and review

## Security and Governance

- Least-privilege access through RBAC
- Managed identities for automation
- Azure Key Vault for secrets where required
- Resource tagging for owner, environment, and cost center
- Approval workflow for financial commitments
